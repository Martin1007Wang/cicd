# Django 待办事项应用的 UI/UX 改进需求文档

## 1. 概述

当前待办事项应用的界面（UI）功能齐全，但缺乏现代设计美感和友好的用户体验（UX）。本文档旨在概述 UI/UX 全面改版的需求，以创建一个更直观、视觉上更具吸引力且看起来更专业的应用程序。

## 2. 核心目标

- **外观与感觉的现代化：** 替换默认的 Bootstrap 4 样式，采用定制的现代化设计。
- **改善用户体验：** 使应用程序更直观，更易于使用。
- **增强视觉层次：** 引导用户的注意力到页面上最重要的元素。
- **确保响应式设计：** 应用程序应在从手机到桌面电脑的所有设备上都能良好地显示和工作。

## 3. 设计与风格指南

### 3.1. 调色板

- **主色：** 一种令人平静的蓝色（例如 `#4A90E2`），用于主要操作，如“添加待办事项”。
- **次色：** 一种浅灰色（例如 `#F5F5F5`），用于背景，以营造空间感。
- **强调色：** 一种充满活力的颜色（例如 `#50E3C2`），用于突出显示重要信息或操作。
- **文本颜色：** 一种深灰色（例如 `#333333`），用于正文文本，以确保可读性。

### 3.2. 字体排印

- **字体家族：** 一种干净、现代的无衬线字体，如来自 Google Fonts 的 'Lato' 或 'Montserrat'。
- **标题：** 更大、更粗的标题，以建立清晰的视觉层次。
- **正文文本：** 舒适易读的字号（例如 16px）。

### 3.3. 布局

- **居中的单栏布局：** 在页面上采用居中的单栏布局，以提供更专注的用户体验。
- **增加间距：** 充分利用空白空间，以减少混乱感并提高可读性。
- **卡片式设计：** 每个待办事项将以卡片形式呈现，并带有微妙的阴影效果，使其更加突出。

## 4. 功能与界面增强

### 4.1. 待办事项卡片

- **状态指示器：** 在卡片左侧使用彩色边框来指示状态（例如，绿色代表“已完成”，灰色代表“待处理”）。
- **更清晰的操作：** “删除”和“完成”操作将更加醒目，并在视觉上有所区分。
- **悬停效果：** 在待办事项上添加微妙的悬停效果，为用户提供视觉反馈。

### 4.2. 输入表单

- **改进样式：** 输入框和“添加”按钮的样式将与新的调色板和设计保持一致。
- **更明确的行动号召：** “添加”按钮将更加突出，以鼓励用户添加新的待办事项。

### 4.3. 头部与页脚

- **头部：** 一个带有应用标题的简洁头部。
- **页脚：** 一个包含版权信息或其他相关链接的简单页脚。

## 5. 实施细节

- **框架：** 现有的 Bootstrap 4 将升级到 Bootstrap 5，以利用其更现代的组件和实用工具。
- **自定义 CSS：** 将创建一个新的 `custom.css` 文件，用于编写自定义样式，以覆盖和扩展 Bootstrap。
- **Google Fonts：** 选定的字体将通过在 `base.html` 文件中引入的方式从 Google Fonts 导入。
- **文件结构：** 对于每个被修改的文件，其原始版本将被重命名并添加 `_original` 后缀（例如，`index.html` 变为 `index.html_original`）。
